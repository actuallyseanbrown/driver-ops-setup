# WezTerm

Merge `wezterm.lua` into Windows `%USERPROFILE%\.wezterm.lua`.

Leader = `Ctrl+a`

| Keys | Action |
|------|--------|
| `Ctrl+a` then `d` | `cd ~/driver-ops && yazi` |
| `Ctrl+a` then `n` | `cd ~/driver-ops && nvim .` |
| `Ctrl+a` then `c` | `cd ~/driver-ops && claude` |
| `Ctrl+a` then `s` / `v` | Split down / right |
| `Ctrl+a` then `h j k l` | Move panes |

Note: Leader+`v` is **split**, not VisiData. VisiData is yazi Enter on data files or `v d` in yazi.
